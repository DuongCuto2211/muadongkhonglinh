NHẠC NỀN

Hãy upload file MP3 của bạn vào thư mục này và đặt tên:
  nhac-lofi.mp3

Đường dẫn mặc định trong config.js là music/nhac-lofi.mp3.
Bạn có thể đổi đường dẫn trong config.js nếu muốn dùng tên file khác.

Website chỉ thử phát nhạc sau khi khách nhấn nút MỞ THƯ. Nếu file chưa có hoặc trình duyệt không phát được, website vẫn hoạt động bình thường.
