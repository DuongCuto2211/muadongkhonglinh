# Website thiệp mời chụp kỷ yếu

## Chạy thử
- Giải nén ZIP.
- Mở `index.html` bằng Chrome, Edge hoặc Safari.
- Trang đã responsive cho điện thoại và máy tính.

## Tùy chỉnh nội dung
Mở `index.html` bằng VS Code / Notepad:
- Thời gian, địa điểm, lịch trình: tìm phần `Thông tin buổi chụp`.
- Lời mời: tìm phần `Gửi những người bạn của mình!`.
- Dress code: sửa nội dung và màu ở phần `dress`.
- Có thể thay nội dung mẫu trực tiếp trong HTML.

## Thêm ảnh và nhạc
- Album: nhấn **Thêm ảnh vào album**, chọn nhiều ảnh cùng lúc.
- Nhạc: nhấn **Thêm nhạc MP3**, chọn file MP3.
- Bản hiện tại xem trước ảnh/nhạc trên thiết bị đang mở trang; file không tự tải lên máy chủ.

## Bật sổ lưu bút công khai cho tất cả khách
Mặc định, lưu bút dùng `localStorage`, nghĩa là chỉ lưu trên trình duyệt/thiết bị hiện tại. Muốn mọi người nhìn thấy lời chúc của nhau khi truy cập từ điện thoại khác, cần kết nối backend. Cách nhanh là dùng Supabase:

1. Tạo project tại https://supabase.com/
2. Mở **SQL Editor** và chạy:

```sql
create table public.guestbook (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) <= 40),
  message text not null check (char_length(message) <= 500),
  created_at timestamptz not null default now()
);

alter table public.guestbook enable row level security;

create policy "Anyone can read guestbook"
on public.guestbook for select
to anon using (true);

create policy "Anyone can add guestbook notes"
on public.guestbook for insert
to anon with check (
  char_length(name) between 1 and 40
  and char_length(message) between 1 and 500
);
```

3. Trong Supabase vào **Project Settings → API** và lấy Project URL + anon/public key.
4. Mở `index.html`, tìm hai dòng gần cuối:

```js
const SUPABASE_URL = '';
const SUPABASE_ANON_KEY = '';
```

Điền URL và anon key vào giữa dấu nháy. Chỉ dùng anon/public key ở trình duyệt, tuyệt đối không đưa `service_role` key lên website.
5. Đưa thư mục website lên hosting tĩnh (ví dụ GitHub Pages, Netlify hoặc Vercel). Khi đó mọi người truy cập cùng website sẽ đọc và gửi lời chúc vào cùng sổ lưu bút.

> Lưu ý: upload ảnh/MP3 trong bản hiện tại là xem trước cục bộ, không phải album dùng chung. Muốn khách ở thiết bị khác cùng xem album, cần tải ảnh lên dịch vụ lưu trữ (ví dụ Supabase Storage) rồi lưu URL ảnh.
